# تقرير مشروع نظام قاعدة بيانات العيادة الذكية (Smart Clinic Database System)

## مقدمة
نظام قاعدة بيانات MySQL معيارية لعيادة خارجية خاصة في المملكة العربية السعودية. يدير النظام المرضى، الموظفين، المواعيد، العلاجات، الوصفات الطبية، مخزون الأدوية، والمدفوعات.

## أعضاء الفريق

| اسم الطالبة | الرقم الجامعي | الدور |
|---|---:|---|
| جمانة سعيد عطيف | 250042243 | قائدة المجموعة ومديرة المستودع |
| سيرين عبد الله الغامدي | 240015574 | تصميم قاعدة البيانات وتوثيق EER |
| لين سلطان الشمري | 240016807 | تنفيذ SQL والاختبار |
| بدور حمد الرشيدي | 230009312 | لقطات الشاشة، التقارير، ومراجعة الجودة |

## المميزات الرئيسية
- **تخصص EER**: تقسيم الأشخاص إلى (مريض/موظف) والموظفين إلى (طبيب/موظف استقبال).
- **الجداول**: 11 جدولاً معيارياً مع مفاتيح أساسية وأجنبية وقيود التحقق.
- **البيانات**: ما لا يقل عن 5 سجلات عينة في كل جدول بأسماء سعودية وهمية.
- **عمليات SQL**: تتضمن الاستعلامات المعقدة، الربط (JOIN)، الوظائف التجميعية، والمشغلات (Triggers).

## هيكل قاعدة البيانات
تتضمن قاعدة البيانات الجداول التالية:
- `person` (الأشخاص)
- `patient` (المرضى)
- `employee` (الموظفين)
- `doctor` (الأطباء)
- `receptionist` (موظفي الاستقبال)
- `appointment` (المواعيد)
- `treatment` (العلاجات)
- `medicine` (الأدوية)
- `prescription` (الوصفات الطبية)
- `prescription_item` (عناصر الوصفة)
- `payment` (المدفوعات)

## التوثيق الفني
- **العرض (View)**: `vw_appointment_summary` لملخص المواعيد.
- **المشغل (Trigger)**: `trg_prescription_item_before_insert` للتحقق من مخزون الأدوية وخصمه تلقائياً.
